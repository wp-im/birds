A small WordPress Classic Theme shaped like a calm, feed-first P2 stream in a Classic Mac OS 9 desktop.

== Description ==

Birds uses ordinary WordPress posts, pages, comments, users, categories, search, archives, and menus to create an immediate publishing and reading surface.

== Installation ==

Upload the Birds ZIP through Appearance > Themes > Add New > Upload Theme, then activate it.
