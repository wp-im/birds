Birds is packaged as a small WordPress stack: a Classic Theme for the experience, an optional companion plugin for front-end operations, and WordPress Core for the content itself.

Choose your Birds

Birds Theme 0.2.0
The visual and editorial layer: feed, threads, topics, archives, search, responsive layout, and the Mac OS 9-inspired interface. It works as a conventional WordPress Classic Theme.
Birds Core 0.1.0
The interaction layer: front-end publish, edit, move to trash, open or close replies, and practical reply management for users with the right WordPress capabilities.

For the complete Birds experience shown on this site, install both. The Theme can also run by itself when you only need the feed and thread presentation.

Install the stack

  1. Install and activate the Birds Theme through Appearance → Themes → Add New → Upload Theme, or place the birds folder in wp-content/themes/.
  2. Install Birds Core through Plugins → Add New → Upload Plugin, then activate it for the target site.
  3. Create categories for the topics you want to browse.
  4. Assign the Primary Menu if you need additional navigation.
  5. Use the front-end composer as a logged-in user with permission to publish posts.
  6. Open a post to read its native WordPress thread and reply. Post and reply controls appear according to the user’s normal WordPress capabilities.

Safe by design

Birds Core uses WordPress’ native posts, comments, capabilities, nonces, and admin-post flow. It creates no custom database tables and does not require a custom REST service or a front-end framework. Disable the plugin and the Theme remains a usable feed and thread presentation.
